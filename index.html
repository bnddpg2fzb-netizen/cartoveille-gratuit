Vos données vous appartiennent

Les fiches et les prix sont stockés localement dans ce navigateur. GitHub Pages héberge uniquement les fichiers de l'application, pas vos données commerciales. Safari peut supprimer le stockage local ; exportez vos données régulièrement.

L'import remplace toutes les données locales de cet appareil après confirmation. Pour transférer vers l'iPhone : exportez sur l'iPad, puis importez le fichier sur l'iPhone.
